# Path Finder

As part of Software Sauna code challenge - this repo contains implementation of "Path Finder".

## Run Locally

Clone the project

```bash
  git clone https://github.com/MrMrsic/path-finder.git
```

Go to the project directory

```bash
  cd path-finder
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run dev
```

Open your browser and go to

```bash
  http://localhost:5173/
```

## Running Tests

To run tests, run the following command

```bash
  npm run test
```
